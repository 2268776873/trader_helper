# 隐私与风险提示

## 本地数据

Trade Helper 默认不监听公网端口，不向云端上传账户数据。SQLite 数据库、Excel
工作簿、市场补充文件、报告和备份均保存在用户指定的本地路径。

请勿录入：

- 券商资金账号；
- 登录密码、交易密码或验证码；
- 身份证号、手机号和银行卡号；
- 家庭成员身份信息；
- 与策略无关的其他金融账户。

本地数据库和备份仍属于敏感个人财务数据。用户应使用 Windows 登录密码、磁盘
加密和受控备份目录保护文件，不应把真实 `var` 目录提交到 Git。

## 投资风险

- 软件输出是规则化执行建议，不构成收益保证。
- ETF、QDII、汇率、溢价、流动性和跟踪误差均可能导致亏损。
- 免费公开数据没有交易所级实时性承诺，异常时软件默认阻断。
- 250日回撤和历史回放不预测未来。
- V1 不采用价格止损，但会进行现金约束、超配再平衡和产品结构审查。
- 软件不自动连接券商；每笔订单由用户独立复核、确认和承担责任。
- 在完成至少20个交易日影子运行和发布验收前，不应把程序升级为自动下单。
