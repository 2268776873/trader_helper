# 真实账户核对与影子运行最小数据清单

历史成交明细不是开始使用 Trade Helper 的前置条件。当前版本的决策以当前账户快照、现金流水和之后记录的真实成交为准。

## 首次核对需要用户提供

- 数据截至日期和时间；
- 配置中三只 ETF 各自的当前持有份额与当前市值；
- 券商账户中的可用现金；货币基金市值按现金计入；
- 当时仍未成交或部分成交的委托；
- 快照当日尚未反映在余额中的存款、取款或例外交易。

以上数据必须满足“现金 + 三项持仓市值 = 账户总资产”。不一致时系统进入 `RECONCILIATION_REQUIRED`，不会生成可执行建议。

## 历史数据何时才需要

只有在需要还原历史资金流水、持仓成本或形成完整审计账本时，才补充历史成交和存取款。补充时至少需要交易日期、标的、买卖方向、成交份额、成交价格和实际资金流；当前策略不依赖历史持仓成本做决策。

## 每个影子运行日需要

- 市场价格与实时估值由系统自动采集，用户不提供行情截图或市场数据；
- 账户没有变化时无需重复录入持仓与现金；
- 发生真实成交、存取款或账户变化时由用户记录；用户也可以提供券商成交截图，由维护者代录；
- 对软件建议记录未操作、已下单、部分成交或全部成交。

影子运行只生成建议，不自动下单。即使近期没有交易，只要当天账户和行情数据真实、建议状态得到记录，该交易日仍可作为有效影子运行证据。
