# 个人资产配置执行策略 V1 评审稿

版本：personal-v1  
日期：2026-07-30  
状态：`ACTIVE`（用户已确认）

## 1. 策略目标

本策略服务于长期资产积累，不选股、不预测短期涨跌，以规则化投入、风险分散和避免情绪交易为主要目标。

它不承诺最高收益，也不承诺本金安全。评价标准依次为：

1. 用户能够长期坚持；
2. 极端行情下不突破现金底线；
3. 不因ETF溢价或错误数据支付不合理价格；
4. 长期保持目标风险暴露；
5. 在以上条件满足后争取合理收益。

适用前提：

- 投资期限原则上不少于10年；
- 5万元战略现金不承担家庭应急金功能；
- 另有约10万元家庭应急资金，不计入投资组合；
- 用户能够承受权益资产阶段性大幅回撤；
- 第一阶段全部订单由用户人工确认和下单。

V1不因政策新闻、短期估值或市场观点临时改变目标比例。

## 3. 初始资金

总资产按50万元初始化：

- 标普500：6万元；
- 纳指100：6万元；
- 红利低波：3万元；
- 策略现金：35万元。

策略现金分为：

- 基础建仓池：12.5万元；
- 标普回撤池：8万元；
- 纳指回撤池：4.5万元；
- 红利回撤池：5万元；
- 战略现金底线：5万元。

资金池是预算记账，不需要分别开设银行账户。任何建议均不得使策略现金低于5万元。

用户实际只持有三只权益ETF和一只货币基金。所选货币基金的全部市值统一计入策略现金，
不要求用户把货币基金拆成不同账户或份额。基础建仓池、三个回撤池和战略现金均由系统
在内部虚拟账本中维护，用户只核对货币基金总市值。

### 3.1 后续存取款

- 每月计划新增资金暂定16,667元，仅用于预算和提醒；
- 用户每月实际转入、转出金额以资金流水为唯一依据；
- 每笔存取款记录时间、金额、类型和备注后，系统立即重算总资产、现金比例、欠配金额、资金池可用额和建议；
- 实际金额与计划金额不同不视为错误，也不要求补足差额；
- 实际存款按70%进入基础建仓池、30%进入回撤池；回撤部分按标普45%、纳指25%、红利30%分配；
- 实际取款依次扣减基础建仓池、按比例扣减三个回撤池，最后才扣战略现金；
- 取款后现金低于5万元时暂停所有新增买入，直至现金恢复；
- 系统不会仅因用户取款自动卖出权益资产；若现金不足以完成计划取款，必须先由用户确认新的卖出或资金安排；
- 如果取款金额超过货币基金/现金余额，系统进入人工策略评审，不自行卖出三只权益ETF；
- 未记账的存取款会导致建议失真，因此在生成当日建议前必须完成账户对账。

## 4. 基础建仓

2026年9月至2027年6月，每月第10个A股交易日释放12,500元，未使用预算结转，
单月最多执行25,000元。

选择顺序：

1. 计算三类资产相对目标金额的欠配；
2. 按欠配金额由大到小检查；
3. 第一名不满足数据或溢价条件时检查下一名；
4. 全部不合格则预算继续保留。

执行比例：

| 资产 | 全额 | 半额 | 阻断 |
|---|---:|---:|---:|
| 标普、纳指 | 溢价≤1% | 1%＜溢价≤2% | 溢价＞2% |
| 红利低波 | 溢价≤0.5% | 0.5%＜溢价≤1% | 溢价＞1% |

## 5. 回撤加仓

回撤统一显示为正数。标普和纳指使用指数、美元兑人民币和必要的盘中市场变化构造人民币参考价值，
不得直接使用场内ETF价格计算回撤；红利低波优先使用复权净值。

| 资产 | L1 | L2 | L3 |
|---|---|---|---|
| 标普 | 8% / 2万元 / 溢价≤2% | 15% / 2.5万元 / ≤2% | 25% / 3.5万元 / ≤1.5% |
| 纳指 | 10% / 1万元 / ≤2% | 20% / 1.5万元 / ≤2% | 30% / 2万元 / ≤1.5% |
| 红利 | 5% / 1万元 / ≤0.5% | 10% / 1.5万元 / ≤0.5% | 15% / 2.5万元 / ≤0.5% |

档位只有实际成交金额才计入完成。部分成交只保留剩余金额。
一次跌穿多个档位时按浅到深处理，不在同一天强制买完。

多资产同日触发顺序：

1. 已触发的最深档位优先；
2. 档位深度相同，欠配金额较大者优先；
3. 仍相同则按标普、纳指、红利固定顺序；
4. 回撤建议优先于当月基础建仓；
5. 所有订单共同受单日4%上限约束。

## 6. 数据与QDII溢价

买入使用卖一价，卖出使用买一价。两个独立估值源分别计算溢价，使用较保守结果。

下列任一情况发生时禁止生成可执行买单：

- 只有一个可靠估值源；
- 两个估值源计算的溢价相差超过0.5个百分点；
- 估值超过5分钟未更新；
- 指数、汇率或账户数据日期异常；
- 基金停牌、交易异常或无法成交；
- 基金发布显著溢价或临时停牌公告，且无法确认风险已经解除；
- 卖一价超过最高允许买价。

中美政策、利率和新闻只进入风险面板，不直接产生买卖信号。
QDII额度、申购限制、基金公告和溢价直接影响是否允许交易。

## 7. 卖出与再平衡

V1不采用价格止损。指数下跌本身不会触发卖出。

卖出仅用于以下情况：

### 7.1 超配再平衡

- 超过允许上限：立即停止继续买入；
- 连续20个交易日仍超过上限：建议卖回允许上限；
- 超过目标比例10个百分点：不等待20日，建议卖回允许上限；
- 优先使用新增资金修复权重，能不卖则不卖。

### 7.2 极端QDII溢价

当标普或纳指ETF溢价达到8%，且该资产权重高于目标时，可建议卖出超过目标的部分。
如果存在同指数、流动性合格且溢价明显更低的替代产品，应优先评估等风险切换，而不是取消长期指数敞口。
8%是V1待历史验证参数，不作为无条件套利保证。

### 7.3 产品结构变化

清盘、合并、更换指数、长期跟踪恶化、流动性严重下降或交易机制发生重大变化时，
系统只输出“退出评估”，不得未经人工确认自动卖出。

## 8. 状态机

回撤档位状态：

- `ARMED`：等待回撤；
- `TRIGGERED`：回撤已满足，但尚未允许买入；
- `PARTIALLY_FILLED`：部分成交；
- `FILLED`：本周期完成；
- `DISABLED`：数据异常或人工关闭。

所有档位仅在以下任一条件满足时重置：

- 人民币参考价值创出新的250日最高值；
- 回撤缩小至2%以内并连续保持20个交易日。

## 9. 下单与用户确认

- 使用限价单；
- 100份整手向下取整；
- 单日累计买入不超过组合总资产4%；
- 单笔计划超过1万元时客户端建议拆单；
- 不在开盘后30分钟内执行；
- 14:50以后不产生新建议；
- 未成交部分不追价，下一交易日重新计算。

客户端必须同时显示：原始数据、数据来源、时间戳、溢价、回撤、权重、资金池、
触发档位、最高限价、建议数量和不交易原因。

### 9.1 建议与成交分离

生成建议不代表已经交易。每条建议单独记录以下执行状态：

- `PENDING_CONFIRMATION`：等待用户处理；
- `NOT_ATTEMPTED`：用户因忙碌或其他原因没有下单；
- `ORDER_SUBMITTED`：已经提交委托但尚未确认成交；
- `PARTIALLY_FILLED`：部分成交；
- `FILLED`：全部成交；
- `CANCELLED`：用户撤单；
- `EXPIRED`：当日未成交失效；
- `REJECTED`：券商拒单或交易失败。

只有实际成交数量和成交价格能够改变持仓、现金及档位完成金额。
未下单、未成交、撤单和拒单只保留审计记录，下一交易日重新计算，不追价、不把原建议自动顺延为成交。

客户端应允许用户用最少操作完成反馈：

- “未操作”；
- “已下单未成交”；
- “部分成交”并填写数量和价格；
- “全部成交”并填写数量和价格；
- “撤单/失败”并可选填写原因。

Excel作为批量导入、导出和备份方式，客户端作为日常操作入口。

## 10. 可靠性与变更规则

策略通过以下方式建立可信度，而不是依赖一次回测收益：

- 公式、边界、状态转换和幂等性自动测试；
- 多数据源交叉验证，异常时默认阻断；
- 历史回放不得使用未来数据；
- 同时报告收益、最大回撤、波动、换手、现金占用和参数敏感性；
- 对比不止损、价格止损和仅再平衡卖出；
- 分解指数、汇率和ETF折溢价贡献；
- 至少20个A股交易日影子运行；
- 所有建议记录配置版本和完整原因；
- 每半年评审一次，不因近期涨跌修改规则。

## 11. 定稿前仍需验证

- 免费数据源对QDII盘中估值的连续稳定性；
- 250日人民币参考价值的历史数据完整性；
- 8%极端溢价卖出规则的历史效果；
- 回撤档位和基础投入节奏的参数敏感性；
- 当前三只ETF与同指数备选产品的长期费用、规模、流动性和申赎状态；
- 用户真实份额、可用现金和资金池余额。

上述事项不影响开发建议系统，但在影子运行通过前，程序不得升级为自动下单。

## 12. 用户执行约束

为了让程序建议与真实账户保持一致，用户同意：

- 不进行建议之外的交易；如确有例外，必须在下一次建议前完整补录；
- 每笔成交回填实际成交时间、方向、代码、数量和成交价，不能只填写计划值；
- 每笔存取款及时记录，以实际到账金额为准；
- 不使用融资、融券、期权、质押或其他杠杆改变本账户风险；
- 不在本策略账户混入其他股票、基金或用途不明的现金；
- 账户内只维护三只指定权益ETF和一只已配置的货币基金；
- 不自行替换三只ETF；产品替换必须先经过策略评审；
- 家庭应急金与策略现金分开，不把5万元战略现金当作全部应急资金；
- 当程序显示数据异常、估值冲突或`BLOCKED`时不绕过限制追价；
- 至少在交易日建议生成前核对账户总资产、现金和持仓；
- 接受权益组合可能出现较大阶段性回撤，并确保未来数年没有必须依靠该账户支付的刚性支出。

系统侧必须提供对账差异提醒。发现券商账户与本地账本不一致时，状态变为
`RECONCILIATION_REQUIRED`，在差异处理前不得输出新的可执行建议。
