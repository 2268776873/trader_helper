# 客户端每日流程

在客户端“数据中心”可以完成日常输入与决策：

1. 每日任务会自动补种随包附带的官方 2026 交易日历（`data/calendar_2026.csv`，
   仅当日历缺少当天日期时导入），休市日自动跳过；如需手动覆盖或导入其他年份，
   点击“导入交易日历”选择包含 `trading_date,is_open` 的 CSV；
2. 每个交易日在 14:00–14:50 内点击“自动采集行情”；系统自动获取三个标的的
   多源价格与两路实时估值，不要求用户提供行情截图或填写市场数据；
3. 检查三个标的是否全部 READY；
4. 点击“运行当日决策”；
5. 回到主界面复核建议，在券商客户端人工下单；
6. 使用“未操作”“已下单”或“回填成交”记录真实结果。

休市日会安全跳过。当天已经存在 READY 或 NO_ACTION 决策时，重复点击不会生成第二批
建议；当天只有 BLOCKED 记录时，允许修复账户、日历或行情后重新运行。

客户端不会自动下单，也不会绕过账户对账、行情时效、双源一致性、现金底线和决策时间窗。
