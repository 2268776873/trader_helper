# 个人策略 V1 黄金场景

状态：待用户确认量化结果，程序配置保持 `DRAFT`。

## 当前固定前提

- 标普500 / 纳指100 / 红利低波 / 现金目标比例：40% / 25% / 25% / 10%。
- 买入后单个资产不得超过其目标比例加5个百分点。
- 单日累计买入不得超过总资产4%。
- 买入后现金不得低于5万元。
- 所有建议按100份整手向下取整，不追价。
- 回撤使用正数表达，例如 `9%` 表示从250日高点回撤9%。
