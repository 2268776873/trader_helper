# 客户端行情采集

客户端侧边栏进入“数据中心”，点击“自动采集行情”。正常使用不需要准备 JSON、
行情截图、估值、指数、汇率或公告输入。

采集在后台线程执行，界面不会因网络请求停止响应。结束后数据中心和主仪表盘自动刷新：

- “采集完成”：三个标的全部 READY，多路价格与实时估值一致；
- “采集完成（降级可用）”：三个标的全部 READY，但某个冗余公共源异常；
- “采集已阻断”：至少一个标的未达到 READY，不会生成交易建议。

系统自动采集新浪、东方财富和腾讯的 ETF 行情，并从东方财富与腾讯取得两路实时参考净值。
任一关键字段缺失、超过五分钟、价格或估值冲突时都会阻断并保存在审计记录中。指数、汇率
和人工公告不再是决策必填项；用户只维护真实成交、存取款和账户变化。

`config/market_supplement.example.json` 仅保留为开发与故障取证工具，不属于用户日常流程。

开发环境默认读取 `config/personal_v1.json`；打包版本读取内置配置。需要明确指定配置时，
设置环境变量 `TRADE_HELPER_CONFIG`。
