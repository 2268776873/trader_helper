# 客户端行情采集

客户端侧边栏进入“数据中心”，点击“采集当日行情”，选择按
`config/market_supplement.example.json` 准备的当日 JSON 文件。

采集在后台线程执行，界面不会因网络请求停止响应。结束后数据中心和主仪表盘自动刷新：

- “采集完成”：三个标的全部 READY，公共源无异常；
- “采集完成（降级可用）”：三个标的全部 READY，但某个公共源异常，独立券商报价已补位；
- “采集已阻断”：至少一个标的未达到 READY，不会生成交易建议。

补充文件必须填写带时区的 `observed_at`，并使用当日、真实、可追溯的数据来源。客户端会
在联网前完成 JSON 结构、来源名称、正数和有限数值校验。源异常、估值冲突、过期数据和
公告阻断都会保存在行情快照审计记录中。

开发环境默认读取 `config/personal_v1.json`；打包版本读取内置配置。需要明确指定配置时，
设置环境变量 `TRADE_HELPER_CONFIG`。
