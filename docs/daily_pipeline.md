# 每日生产流水线

每日调用在工作日 14:40 启动，但最终是否运行策略仍由数据库中的显式
A 股交易日历判断。流水线依次执行：

1. 采集新浪、东方财富、腾讯的多源 ETF 行情与两路实时参考净值；
2. 校验来源时间、价格偏差和实时估值偏差；
3. 仅在三个标的行情快照全部 READY 时进入当日决策；
4. 决策服务再次检查交易日、14:00–14:50 时间窗、账户对账和持久化状态。

正常运行不需要准备人工行情文件。注册 Windows 计划任务（如明确需要）可以使用：

```powershell
.\scripts\register_daily_task.ps1
```

手工演练完整流水线：

```powershell
.\scripts\run_daily_pipeline.ps1
```

如果关键自动源缺失、过期、冲突，任一标的未达到 READY，或决策检查失败，脚本返回非零
状态且不会生成可执行建议。冗余公共源临时失败但仍有两路价格和两路估值时，采集输出会
显示 `ok: true` 与 `degraded: true`，并保留失败源审计记录。
