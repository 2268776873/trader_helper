# 动态资金池规划

资金池是系统虚拟账本，不要求用户手工拆分现金。整体资产目标、现金底线、基础建仓计划和
回撤档位保持不变，但每次真实现金事件都会重新计算池余额并留下审计证据。

## 当前事件规则

- 存款：沿用冻结配置，70% 进入基础池，30% 进入三个回撤池；回撤池再按
  SP500 45%、NASDAQ 25%、DIVIDEND 30% 分配。
- 取款：基础池优先，其次三个回撤池按当前余额同比例减少，最后才减少战略现金。
- 卖出成交：采用已批准方案 A，实际净所得全部进入战略现金，不自动触发买入。
- 买入成交：按建议记录的资金来源扣减基础池或对应回撤池；部分成交只扣实际金额。

## 原子性与审计

客户端“存取现金”会在一个 SQLite 事务内完成：

1. 以最近账户快照为基线，叠加其后的真实成交；
2. 校验账户现金与五个资金池总额一致；
3. 计算事件后的五个资金池；
4. 写入现金流水和新的账户快照；
5. 更新策略运行状态；
6. 写入包含事件前后余额、分配规则和来源引用的 `cash_pool_events`。

任一步失败都会整体回滚。客户端“历史审计”同时展示现金流水和资金池规划事件。未来若要
把战略现金重新部署到基础池或回撤池，系统应先生成独立、可确认的重分配计划；不得在卖出
成交时静默执行。
