# 客户端备份与恢复

从客户端侧边栏进入“备份恢复”。

“创建校验备份”使用 SQLite 在线备份机制取得一致快照，并生成 `.thbackup` 文件。归档中
包含数据库和清单，清单记录格式版本、数据库大小与 SHA-256。

“从备份恢复”会依次执行：

1. 在当前数据库旁创建带时间戳的 `pre-restore` 安全备份；
2. 校验归档只包含预期文件；
3. 校验格式版本、文件大小、SHA-256；
4. 运行 SQLite `integrity_check` 并确认关键 Trade Helper 表存在；
5. 使用临时文件原子替换当前数据库；
6. 刷新客户端仪表盘。

恢复失败不会覆盖当前数据库；恢复成功后仍可使用自动创建的安全备份回滚。备份包含个人
账户与交易数据，应保存在受控位置，不应提交到 Git 仓库或随发布包分发。
